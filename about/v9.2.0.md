## Decisões e trade-offs

### SimpleMailMessage — texto plano

`SimpleMailMessage` foi escolhido por simplicidade e clareza.
Para e-mail HTML com template (Thymeleaf), seria necessário `MimeMessageHelper`.
Texto plano atende o objetivo de demonstrar o padrão completo sem adicionar
dependência de template engine.

**Evolução:** `MimeMessageHelper` + template HTML em `resources/templates/`.

### GreenMail — SMTP embarcado

GreenMail sobe um servidor SMTP real em memória, sem processo externo.
Porta aleatória via `ServerSetup(0, ...)` evita conflitos entre execuções.

```java
greenMail = new GreenMail(new ServerSetup(0, "127.0.0.1", "smtp"));
greenMail.start();
int port = greenMail.getSmtp().getPort();
```

O teste verifica o e-mail real recebido via `greenMail.getReceivedMessages()`:
destinatário, subject com UUID, corpo com texto transcrito.

### Excluir RabbitAutoConfiguration no teste

O `EmailNotificationAdapterTest` usa `@SpringBootTest` mas não precisa de RabbitMQ.
Sem exclusão, o `SimpleMessageListenerContainer` tenta conectar ao broker
e gera warnings de conexão recusada.

```java
@TestPropertySource(properties = {
    "spring.autoconfigure.exclude=org.springframework.boot.autoconfigure.amqp.RabbitAutoConfiguration"
})
```
