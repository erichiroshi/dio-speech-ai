A arquitetura do projeto é baseada em uma estrutura de camadas, onde a API atua como intermediária entre o cliente e os serviços de IA externos. O uso de cache com Redis melhora a performance, enquanto a integração com Prometheus e Grafana permite monitorar métricas essenciais para garantir a saúde e eficiência da aplicação.
