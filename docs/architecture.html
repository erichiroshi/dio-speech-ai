Nível 3 — Componentes (dentro da API)

  POST /api/transcriptions
  Authorization: Bearer <JWT>
         │
         ▼
  ┌──────────────────────────────────────────────────────────────────────┐
  │  SecurityFilterChain (v3.4.0)                                        │
  │    JwtAuthFilter → valida HS256 → popula SecurityContext             │
  │    /actuator/health, /actuator/prometheus, /auth/token → públicos    │
  │    /api/transcriptions → requer ROLE_USER                            │
  └───────────────────────────┬──────────────────────────────────────────┘
                              │
  ┌───────────────────────────▼──────────────────────────────────────────┐
  │  MdcLoggingFilter (v2.2.0)                                           │
  │    requestId (UUID), httpMethod, requestUri → MDC                    │
  │    X-Request-Id header na resposta                                   │
  └───────────────────────────┬──────────────────────────────────────────┘
                              │
  ┌───────────────────────────▼──────────────────────────────────────────┐
  │  TranscriptionController                                             │
  └───────────────────────────┬──────────────────────────────────────────┘
                              │ transcribe(file)
  ┌───────────────────────────▼──────────────────────────────────────────┐
  │  TranscriptionService                                                │
  │    validate() → MDC(fileName, fileSizeBytes) → metrics.recordSize()  │
  │         │                                                            │
  │    CacheService (v2.4.0)                                             │
  │         ├── SHA-256(bytes) → "transcription:{hash}"                  │
  │         ├── HIT  → metrics.recordCacheHit() → return cached=true     │
  │         └── MISS → metrics.recordCacheMiss() → chama Whisper         │
  │                          │                                           │
  │    metrics.recordWhisperCall(supplier) ← Timer p50/p95/p99           │
  └───────────────────────────┬──────────────────────────────────────────┘
                              │
  ┌───────────────────────────▼──────────────────────────────────────────┐
  │  SpeechToTextClient (v3.2.0)                                         │
  │    @Retry(whisper)        → 3x, backoff 500ms→1s→2s                  │
  │    @CircuitBreaker(whisper) → CLOSED/OPEN(30s)/HALF_OPEN(3 calls)    │
  │    fallback → ServiceUnavailableException → 503                      │
  │         │                                                            │
  │    WebClient POST speaches:8000/v1/audio/transcriptions              │
  └──────────────────────────────────────────────────────────────────────┘

  ┌──────────────────────────────────────────────────────────────────────┐
  │  TranscriptionMetrics (v2.5.0)                                       │
  │    Counter: requests.total{status=success|error}                     │
  │    Counter: cache.total{result=hit|miss}                             │
  │    Timer:   whisper.duration (p50/p95/p99 + histograma)              │
  │    Distribution: file.size.bytes                                     │
  └──────────────────────────────────────────────────────────────────────┘

  ┌──────────────────────────────────────────────────────────────────────┐
  │  GlobalExceptionHandler                                              │
  │    TranscriptionException     → 400  │  ServiceUnavailable → 503     │
  │    JwtValidationException     → 401  │  IllegalArgument   → 400      │
  │    NoResourceFound            → 404  │  Exception         → 500      │
  │    requestId do MDC incluído no ProblemDetail                        │
  └──────────────────────────────────────────────────────────────────────┘
