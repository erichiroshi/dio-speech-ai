Nível 3 — Componentes (dentro da API)

Classes e responsabilidades dentro do container dio-speaches-ai.

  POST /api/transcriptions
         │
         ▼
  ┌─────────────────────────────────────────────────────┐
  │ TranscriptionController                             │
  │  @RestController — recebe MultipartFile             │
  └───────────────────────┬─────────────────────────────┘
                          │ transcribe(file)
                          ▼
  ┌─────────────────────────────────────────────────────┐
  │ TranscriptionService                                │
  │  • validate() — tipo e tamanho                      │
  │  • metrics.recordFileSize()                         │
  │  • metrics.recordWhisperCall( supplier )  ──────────┼──► TranscriptionMetrics
  │  • metrics.recordSuccess() / recordError()          │     Counter, Timer, Distribution
  └───────────────────────┬─────────────────────────────┘
                          │ transcribe(file)
                          ▼
  ┌─────────────────────────────────────────────────────┐
  │ SpeechToTextClient                                  │
  │  @Component — WebClient                             │
  │  POST speaches:8000/v1/audio/transcriptions         │
  └─────────────────────────────────────────────────────┘
                          │
                          ▼
                   WhisperResponse { text }
                          │
                          ▼
                 TranscriptionResponse { text, fileSizeBytes }

  ┌─────────────────────────────────────────────────────┐
  │ GlobalExceptionHandler  @RestControllerAdvice       │
  │  TranscriptionException → 400 ProblemDetail         │
  │  IllegalArgumentException → 400                     │
  │  Exception → 500                                    │
  └─────────────────────────────────────────────────────┘
