🚀 Sobre o projeto

O dio-speech-ai é uma API desenvolvida com Spring Boot para transcrição de áudio utilizando o modelo Whisper via Speaches. O projeto evolui em fases com foco em boas práticas de arquitetura: observabilidade, cache, resiliência e segurança.

Desenvolvido para o desafio DIO × Globant — Java & Spring Boot AI Developer.

📈 Progresso do roadmap

Fase 1 API base — transcrição síncrona, Docker Compose, ProblemDetail ✓ concluída v1.0.0
Fase 2 Observabilidade + Cache — Prometheus ✓ · Logs JSON · Redis · Grafana · Zipkin em andamento v2.1.0+
Fase 3 Resiliência + Segurança — CircuitBreaker · Retry · JWT planejada v3.x.0
Ver roadmap detalhado

⚙️ Como executar

Dois modos de execução disponíveis:

Desenvolvimento — infraestrutura no Docker, app local

docker compose -f docker-compose.dev.yml up -d
./gradlew bootRun --args='--spring.profiles.active=dev'

Produção (simulada) — stack completa containerizada

docker compose up -d
