🚀 Sobre o projeto

O dio-speech-ai é uma API desenvolvida com Spring Boot para processamento e transcrição de áudio utilizando serviços de IA. O projeto evolui com foco em boas práticas de arquitetura, incluindo observabilidade, resiliência e performance.

⚙️ Como executar

O projeto utiliza Docker para facilitar o setup do ambiente.

docker compose up

Após subir os containers, a API estará disponível localmente.
